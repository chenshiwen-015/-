# 封面工坊

中文服装商品封面编辑器。支持批量上传主图、上身图和细节图，按模板自动排版，逐图缩放、移动、调整透明度和抠图，修改文案、字体、背景，并导出 PNG。

全部编辑在浏览器中进行；无需数据库或 OpenAI API Key。AI 抠图首次使用时会下载第三方模型资源。

运行方式：在仓库根目录执行 `python3 -m http.server 8080`，然后访问 `http://localhost:8080`。

静态网站入口为 `index.html`。项目源码与许可见 `source.zip`、`LICENSE-AGPL-3.0.txt` 和 `THIRD_PARTY_NOTICES.txt`。
