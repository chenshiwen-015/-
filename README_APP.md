# 封面工坊
中文服装商品封面编辑器，原生 HTML / CSS / JavaScript，无构建步骤、无需 API Key。

## 启动
```sh
cd cover-studio
python3 -m http.server 8080
```
浏览器访问 http://localhost:8080 。也可将 dist 文件夹部署到静态网站。推荐通过 HTTP(S) 使用；本地直接双击 HTML 时，AI 模型加载和示例素材打包可能受浏览器限制。

## 批量上传与自动排版
1. 在「素材」页填写商品名称；「品牌与商品卖点」中可选填已确认的卖点，每行一项。
2. 点击「批量添加图片」一次添加上身、商品主图、材质/细节图。JPG / PNG / WebP，原图单张最多 15 MB，列表最多 16 张；大图在本机优化至最长 2400px，原文件不变。
3. 按文件名建议「上身 / 商品 / 细节」类型，不认识的文件名保留为「自动分配」，按上传顺序填位。每张图片的类型可以改。此功能不使用视觉 AI 来判断材质、价格或商品属性。
4. 选择模板，点击「按当前模板自动排版」，自动分配图片、完整适配比例，并把名称和本次明确填写的卖点放进该模板的文案。取消「同步填入」可只重排图片。
5. 自动排版后可以独立调整每张图片、抠图、换背景、改文字并导出 PNG。默认勾选「自动裁紧纯色留白」：根据边缘估计外圈留白，将原图按矩形裁紧后适配，裁切范围内的像素保留，不做颜色抠除，也不处理材质图。可取消勾选或在逐图工具中恢复原图。没有自动换装、换脸或自动抠图；需要去底时，在对应素材的「抠图 · 调整」中使用 AI、纯色抠除或手动修边。

图位少时只展示该模板容纳的图片，其余保留在批量列表。图位所需图片不足时会复用上传图，不混入原来的示例照片。街拍清单会根据已提供的商品图数量分配空间。可以切换模板再点自动排版；背景颜色、背景图和字体保留。自动排版会重置图片位置及当前模板勾选同步的文案，「撤销自动排版」可恢复排版前的素材、文案和调整参数。

## 素材与逐图编辑
- 上传模特、商品一至四、拍立得一/二、细节一至三、第二个人物和参考图。支持 JPG/PNG/WebP，每张 15 MB 以内。
- 每张素材卡片点「抠图 · 调整」，预览旁会显示当前图位的缩放、水平/垂直移动、图片适配和不透明度。
- 所有图位独立保存参数。即使借用同一张原图，抠图或透明度也不会联动其他图位。参考图仅用于对照，不参与封面导出。
- 缩放 20%–500%；移动按画框大小计算，图片刚好贴合画框时两个方向仍可移动。支持直接拖动预览图片、方向键移动、Shift+方向键加速。
- 不透明度 0% 为完全透明、100% 为完全可见。选中框只用于提示，不会出现在导出 PNG 中。

## 抠图
1. **AI 智能抠图**：使用精细 isnet_fp16 模型，在浏览器本机处理。首次需要下载模型与运行资源，后续可使用缓存；无图片上传到抠图服务的步骤。
2. **纯色背景抠除**：根据边缘颜色，从图片边缘移除相近、连通的背景，可调容差。适合干净背景；复杂背景或浅色商品应检查边缘。
3. **手动擦除 / 恢复**：在独立窗口使用笔刷，支持调整笔刷、撤销一笔、取消和应用。复杂边缘可用此方式修正。
4. **使用原图**：恢复当前图位；不修改其他图位。也可下载当前图片的透明 PNG。

AI 结果会清理小噪点，排版时自动裁紧透明边缘以充分利用图位。原始素材仍保留，笔刷恢复基于原始像素。图片效果以预览为准；没有成功完成的 AI 请求会明确显示失败并保留原图。

## 背景
每套模板首次使用时默认为纯色背景。「背景」页最上方可选择六种预设颜色、使用取色器或输入十六进制颜色值。点击「上传背景图片」可使用自己的 JPG / PNG / WebP（15 MB 以内），上传后自动应用；「切回纯色背景」可随时恢复所选颜色。已上传的背景会保留在缩略图下，方便重新应用。

时尚街区、温馨室内、户外庭院三个内置 AI 场景收在「内置场景背景（可选）」中。图片背景可独立调整位置、缩放和不透明度，并下载为 PNG。切换模板会分别保留每套模板主动选择的背景与纯色。

背景位于图片下方。先抠除人物/商品的原有背景，或调低其不透明度，新场景才能透出。纸张、右栏等模板装饰会保留。

## 字体
「字体」页分别控制标题、正文和手写装饰：黑体、宋体、楷体、时尚衬线、经典衬线、英文手写。使用本机字体，无额外字体下载；缺失字体按同类回退。「跟随模板」保留各模板原本的搭配。

## 模板库
七种可编辑模板：
- 纸感单品企划：纸张纹理、孔洞、居中商品、箭头标签与胶带。
- 街拍穿搭清单：大幅人物、竖排英文、四件商品清单和叠加人物。
- 双人 Lookbook：两个人物、红色衬线大标题和上下刊物排版。
- AP 杂志拼贴、自然叙事、黑白刊物、暖调典藏。

前三种参考用户提供的版式构成重新绘制，不将参考海报作为不可编辑的整张模板。素材保留，文案编辑区随所选模板变化，只显示当前版式实际使用的字段。例如，纸感模板显示企划标题、左右注释和胶带卖点；街拍模板显示四件商品的图注；Lookbook 显示上下大标题和刊物说明。每套模板分别保存已编辑文案，切换回来可以继续修改。品牌、商品名称和年份属于共用商品资料；不会自动推断或编造商品信息。

素材编辑区也会优先显示当前模板需要的图位，其它图片保留在「其它模板的素材」中。重置只恢复当前模板的文案与样式，不清空上传素材或其它模板的文案。

## 导出与项目
- 1080×1440 或 1080×1620 PNG，与预览共用渲染函数。
- 保存项目 JSON 包括原图、抠图 PNG、独立透明度、裁切、背景、字体和文案。
- v6 项目格式，保存批量素材、分类、本次卖点、各模板的独立文案与背景；兼容旧版 v1/v2/v3/v4/v5。重复使用的批量图片引用已保存的图位，减少项目体积。
- 刷新时会尽力保留当前标签页编辑，超过浏览器存储容量时可能无法保留，请定期下载项目 JSON。
- 商品链接仅记录来源；没有接入抖音页面抓取。素材备注不会直接出现在封面；要展示的信息请填写到文案栏。

## 文件与验证
- dist/index.html / style.css：界面与响应式样式
- dist/app.js：排版、上传、逐图工具、背景字体、项目存取和导出
- dist/template-model.js：模板字段、素材清单与独立文案 / 背景草稿
- dist/batch-layout.js：本机文件名分类、模板图位分配、仅用已填信息组织文案
- dist/image-transform.js：缩放、平移、不透明度校验
- dist/image-tools.js：纯色抠除、AI 掩码噪点清理
- dist/assets/backgrounds/：网页 JPEG、完整生成提示词（原始 PNG 保留在本地项目）
- tests/：几何变换、不透明度、颜色抠除、噪点清理、模板文案与背景切换的回归检查

```sh
node tests/image-transform.cjs
node tests/image-tools.cjs
node tests/template-model.cjs
node tests/batch-layout.cjs
```
